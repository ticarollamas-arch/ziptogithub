Kiwify

  1. Kiwify → Apps → Webhooks → Criar webhook.
  2. Cole a URL abaixo e marque: compra aprovada, reembolso, chargeback, assinatura cancelada e renovada.
  3. Copie o token do webhook para a variável KIWIFY_TOKEN na Vercel.
  4. Em Produto → Configurações, use a página de obrigado abaixo.

Hotmart

  1. Hotmart → Ferramentas → Webhook (API e notificações) → Cadastrar (versão 2.0.0).
  2. Cole a URL abaixo e marque: aprovada, completa, reembolsada, chargeback, cancelada, protesto, cancelamento de assinatura.
  3. Copie o Hottok para a variável HOTMART_HOTTOK na Vercel.
  4. No produto, configure a página de obrigado abaixo.

ZipToGit do .zip pro GitHub

Envie o conteúdo de um arquivo compactado direto para um repositório, com análise de arquitetura por IA.

Abrir ferramenta Ver código
reactviteexpressgithub apiollama

O que faz

Arraste e solte

Detecta ZIP, TAR.GZ, RAR, 7z e APK pelos magic bytes.

Árvore filtrada

Pré-visualiza arquivos e ignora node_modules, .git e builds.

Publica no GitHub

Cria ou atualiza o repositório e a branch com um token seu.

Análise com IA

Relatório de arquitetura e especificação clean-room.

Roda local

Funciona com Ollama no seu PC, sem pagar API.

Seguro por padrão

Bloqueia Zip Slip, zip bomb e aninhamento excessivo.

Como usar

  1. Arraste o arquivo .zip
  2. Confira a árvore de arquivos
  3. Informe token, repositório e branch
  4. Clique em Publicar

Instalação

git clone https://github.com/ticarollamas-arch/ziptogithub.git
cd ziptogithub
npm install
npm run dev
